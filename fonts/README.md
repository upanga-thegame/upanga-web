# Upanga website fonts

The website serves these WOFF2 files locally. The bundled notices contain the
copyright and SIL Open Font License 1.1 for each family.

| Family | Fontsource package | Styles served |
| --- | --- | --- |
| [DM Mono](https://www.npmjs.com/package/@fontsource/dm-mono/v/5.3.0) | `@fontsource/dm-mono@5.3.0` | Normal 400 and 500 |
| [Manrope](https://www.npmjs.com/package/@fontsource-variable/manrope/v/5.3.0) | `@fontsource-variable/manrope@5.3.0` | Normal 400–800 |
| [Space Grotesk](https://www.npmjs.com/package/@fontsource-variable/space-grotesk/v/5.3.0) | `@fontsource-variable/space-grotesk@5.3.0` | Normal 400–700 |

The binaries are copied unchanged from the packages. The CSS preserves their
Unicode subsets and uses the family names already referenced by the site.
